# Syperix

Syperix, savunma teknolojileri, tarım ve yapay zeka alanlarında Ar-Ge yapan bağımsız bir takımdır (kuruluş 2025). Bu depo, takımın tanıtım sitesidir: ekip, aktif projeler (Gök Siper, YZDOSS), Ar-Ge dosyaları, başarılar ve iletişim bilgileri.

**Site:** https://syperix-tr.github.io/Syperix/

Düz HTML, CSS ve JavaScript ile yazılmış statik bir sitedir; GitHub Pages üzerinden `main` dalından yayınlanır. Logo dosyaları (SVG ve PNG haliyle) `assets/` klasöründedir.
